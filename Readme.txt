# Task 3: Basic Vulnerability Scan on Local Host

## Project Overview
This repository contains the results of a vulnerability assessment performed on my local workstation. The objective was to identify security weaknesses and common vulnerabilities using automated scanning tools.

## Key Deliverables
* **Vulnerability Report**: For a comprehensive breakdown of the findings, severity levels, and mitigation strategies, please refer to the attached PDF file: `Vulnerability_Assessment_Report.pdf`.
* **Screenshots**: Visual evidence of the scan configuration, dashboard results, and critical findings are included in the `/screenshots` folder and documented within the PDF.

## Summary of Work
* **Tools Used**: ManageEngine Vulnerability Manager Plus.
* **Scan Target**: Localhost (127.0.0.1).
* **Process**: Performed a full system scan to identify missing patches, insecure configurations, and outdated third-party applications.
* **Findings**: Detailed analysis of Critical and High-severity issues is provided in the PDF, along with recommended fixes.

**Note**: All technical details, CVE analysis, and step-by-step documentation are consolidated in the **Vulnerability_Assessment_Report.pdf** included in this repository.
