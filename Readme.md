Network Packet Capture and Protocol Analysis using Wireshark 📌 Project Overview

This project demonstrates how to capture live network traffic using Wireshark and analyze common network protocols. The goal is to identify different types of network traffic generated during normal system activity and understand how protocols interact at different layers of the network stack.

This task was completed as part of a Cyber Security Internship.

🎯 Objective

Capture live network packets

Identify at least three different network protocols

Analyze packet details such as source, destination, and protocol behavior

Export the captured traffic as a .pcap file

Document findings in a concise report

🛠 Tools Used

Wireshark (Packet capture and analysis)

Linux Terminal

Ping utility 📊 Key Observations

ICMP packets confirmed successful connectivity to Google servers.

DNS traffic revealed domain name resolution processes.

TCP ensured reliable data transmission between hosts.

The capture illustrates real-world network communication behavior.

📄 Packet Capture File

network_capture.pcap Contains all captured traffic used for analysis.

✅ Conclusion

This project provides hands-on experience in capturing and analyzing live network traffic using Wireshark. By identifying ICMP, DNS, and TCP protocols, it demonstrates a foundational understanding of network communication—an essential skill in cybersecurity and network analysis.
